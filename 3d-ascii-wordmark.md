# How the 3D ASCII wordmark is built

`wordmark.svg` is generated by `scripts/make_wordmark_svg.py`:

1. **Letterforms** — `pyfiglet` renders the word (`TD`) in the `ansi_shadow`
   font, which uses solid Unicode block glyphs (`█ ╗ ╝ ║ ╔ ╚`) instead of
   thin ASCII strokes, so it reads well at small sizes.
2. **Extrusion** — the same block of text is drawn ~16 times, each copy
   offset a fraction of a pixel further down-and-right than the last, and
   each colored a step further along a cyan → deep-purple gradient. Stacked
   back-to-front, this fakes a beveled 3D side face without any real 3D
   engine — just layered 2D text.
3. **Wipe-in** — a CSS `clip-path: inset()` animation reveals the whole
   rig left-to-right on load (`steps()` timing keeps it looking like a
   terminal typing effect rather than a smooth fade).
4. **Rocking** — after the wipe finishes, an infinite `scaleX` + `skewY`
   keyframe animation gently squashes and skews the wordmark, which reads
   as a slow rotation around the vertical axis (a real orbit camera would
   need WebGL; this is the 2D-CSS approximation).

Regenerate after changing the word or palette:

```bash
python3 scripts/make_wordmark_svg.py
```

Edit `WORD`, `FONT`, `FRONT_COLOR`, and `BACK_COLOR` at the top of the
script to retheme it.
